## Privacy / data handling

The plugin does not send popup visitor data to Panasys Technologies. It uses browser `localStorage` only to store a popup-specific hidden-until timestamp for the 1-day cooldown after a visitor closes a popup.

If a site owner adds third-party forms, analytics, tracking pixels, embeds, or external media inside popup content, the site owner is responsible for disclosing those tools in their site's privacy policy and complying with applicable laws.
