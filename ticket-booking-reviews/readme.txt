Sell selected seats for movie theaters, cricket matches, football matches, and event passes through WooCommerce.

== Description ==

Ticket Booking & Reviews for WooCommerce adds a Ticket Event content type, event listing shortcode, seat structure builder, frontend booking shortcode, WooCommerce cart/order metadata, and star ratings on event comments.

Admins can build venue layouts for movie theaters, cricket grounds, football stadiums, and general event passes with rows, seat positions, blocked seats, sections/stands, tier-wise seating labels, movie screen placement, and cricket pavilion ends.

== Usage ==

1. Create a WooCommerce product for the ticket price.
2. Add a Ticket Event and choose Movie Theater, Cricket Match, Football Match, or Event Pass.
3. Enter venue, start date/time, WooCommerce product ID, rows, seats per row, seat sections/stands, tier-wise seats, seat position notes, blocked seats, screen position, and pavilion ends as needed.
4. Place `[ticket_booking_events]` on an events page to list available events.
5. Place `[ticket_booking_event id="123"]` on an event page to show the seat map and booking form.
6. Customers select seats and complete checkout in WooCommerce; event and seat details are stored on cart, checkout, and order line items.
