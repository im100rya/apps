Sell selected seats for movie theaters, cricket matches, football matches, and event passes through WooCommerce.

== Description ==

Ticket Booking & Reviews for WooCommerce adds a Ticket Event content type, seat structure builder, frontend booking shortcode, WooCommerce cart/order metadata, and star ratings on event comments.

== Usage ==

1. Create a WooCommerce product for the ticket price.
2. Add a Ticket Event and choose Movie Theater, Cricket Match, Football Match, or Event Pass.
3. Enter venue, start date/time, WooCommerce product ID, rows, seats per row, seat sections, and blocked seats.
4. Place `[ticket_booking_event id="123"]` on an event page.
5. Customers select seats and complete checkout in WooCommerce.
